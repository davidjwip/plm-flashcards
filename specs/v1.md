# v1 — sound-pattern pronunciation practice

Status: **draft v2 — awaiting Dave's approval.** The first draft (a three-mode
spelling-bee app with fixed decks) was rejected by Dave on 2026-10-20: it was not
the game he wanted. This is the replacement.
Owner: Dave approves. Non-goals are as binding as goals.

## 1. What this is

A supervised practice game for a five-year-old learning to read by phonics
pattern. The grown-up picks the sound patterns being taught this week; the app
builds a word set from them and shows one word at a time, very large. The child
reads the word aloud, the grown-up presses **✓ got it** or **✗ not yet**, and the
next word appears. At the end: a score. Every tenth right answer: a small
celebration.

Reference point Dave gave: his own `simpleKindergartenAdditionWebpage` maths game
— same genre of interaction (grown-up supervises, big targets, immediate
feedback, progress and celebration), different content: pronunciation of sound
patterns rather than arithmetic.

## 2. Shape

Single-page static app. No accounts, no backend, no network calls at runtime
beyond its own assets. Works offline after first load, in either orientation.

Two screens:

1. **Setup** — a multi-select list of sound patterns (a collapsible dropdown of
   checkboxes), a live count of how many words that selection yields, and a Start
   button that is disabled until at least one pattern is chosen.
2. **Practice** — the word, huge; a "hear it" hint button; two enormous verdict
   buttons; a position counter and running score; a way back to the patterns.

## 3. Vocabulary

- **Pattern** — a taught sound spelling: `a` (short), `a_e`, `ai`, `ay`, `igh`,
  `ck` … with a human label such as `ai (rain)`.
- **Word bank** — `data/wordbank.json`: every word, tagged with the patterns it
  demonstrates. A word may demonstrate more than one (`train` = `ai` + `a`), and
  appears once regardless of how many of its patterns are selected.
- **Dictionary** — the words built from the current selection: the union of the
  selected patterns' words, alphabetically, no duplicates.

## 4. Behaviours

| ID  | Behaviour                                                                                                                                                                                                                 |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| B1  | **Pattern selection.** A multi-select dropdown of every pattern that has words. Selection persists in `localStorage` on the device.                                                                                        |
| B2  | **Dictionary built from selection.** Multi-select unions the word sets; a word demonstrating two selected patterns appears once. Nothing selected → no words, Start disabled.                                                |
| B3  | **One word at a time, very large.** The child reads it; nothing on screen requires the child to read an instruction.                                                                                                       |
| B4  | **Grown-up verdicts.** `✓ got it` and `✗ not yet`. Each press records the verdict, updates the score and advances. **No timer, no auto-advance** — the screen changes only when an adult presses.                           |
| B5  | **Score and progress.** Position `n of N` and running ✓/✗ counts during the run; a summary at the end with right / not yet / total.                                                                                        |
| B6  | **Celebration every tenth right answer**, shown once, not repeating while the score sits on a multiple of ten.                                                                                                             |
| B7  | **"Hear it" hint.** Speaks the current word with `speechSynthesis` (en-GB). A hint, not the prompt; silently does nothing where speech is unavailable.                                                                     |
| B8  | **Repeat and change.** From the summary: run the same patterns again, or go back and change them.                                                                                                                          |
| B9  | **Path to the party.** A ten-step track fills one step per right answer, resetting at each celebration — the same device as the maths game, so the child sees how close the next party is. A wrong answer does not fill a step. |
| B11 | **Word size.** By default the word is sized responsively (`clamp()`, so it suits the screen). `A−` / `A+` beside it step an explicit size through eight settings (3rem up to 20rem — enough to fill a desktop monitor) the moment the adult asks for one, and that choice is remembered on the device. Buttons disable at the ends of the range. |
| B10 | **Encouragement.** Every right answer flashes a short rotating message (`Nice!`, `Got it!`, …) that fades on its own, never blocks the word or the verdict buttons, and never needs dismissing. A streak counter (🔥 n in a row, best) sits below the buttons. |

## 6. Word bank rules

- Every word is a real, decodable word for the patterns tagged on it.
- Words are ours: invented or ordinary English, never transcribed from printed
  material, a worksheet, a photo or a screenshot.
- No proper nouns, no names — that is a child-identity rule in disguise.
- A word may carry more than one pattern tag; tags must exist in `patterns`.
- `npm run validate:bank` enforces tags, duplicates, and plain lowercase letters.

## 8. Decisions

| #   | Decision                                              | Alternative rejected, and why                                                                                       |
| --- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| D1  | Vite + TypeScript, vanilla DOM, no framework          | Vue (as in the maths game) — the layering that makes that app testable is the engine/composable split, not the framework; vanilla keeps the bundle ~7 kB and the repo already has the harness |
| D2  | One word at a time, adult-pressed verdicts            | child self-marking, timers, auto-advance — this game is explicitly supervised, and a timer would reward speed over pronunciation |
| D3  | Pattern tags on words, dictionary built by union      | one fixed deck per pattern — Dave asked for multi-select patterns, and real words demonstrate several patterns at once |
| D4  | `speechSynthesis` for the hint                        | pre-generated audio now — the hint is optional; generated UK-voice audio is still the plan for a later step, and the earlier decision (one UK female voice) stands |
| D5  | Progress in `localStorage`, nothing synced            | accounts and cloud sync — out of scope, and would require collecting child data                                      |
| D6  | Static hosting; Pages now, Cloudflare later           | homelab hosting — the app must work on an iPad anywhere, and `base: './'` keeps the build host-agnostic              |

## 9. Explicitly out of scope for v1

Spelling input, dictation, bee rounds, per-word history, multi-child profiles,
adaptive difficulty, parent dashboards. The rejected first draft's three modes
are not coming back in v1.
