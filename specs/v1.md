# v1 — practice app for spelling and blending

Status: **approved 2026-10-20 by Dave.** Implementation may proceed, one
acceptance criterion at a time, via failing test first (`AGENTS.md`).
Owner: Dave approves. Drafted by the agent from the project brief.
Non-goals are as binding as goals.

## 1. Problem

A 4½-year-old is learning to read and spell by phonics pattern, and is being
prepared for spelling-bee style recall. Paper worksheets give no audio and no
repeatable check; generic phonics apps do not follow the pattern order being
taught, so they introduce spellings the child has not met. He needs something he
can use on his own for five minutes, and a parent needs to know which words are
not yet solid.

## 2. Product shape

A single-page static web app. No accounts, no backend, no network calls at
runtime beyond loading its own assets. Works on an iPad in either orientation,
offline after first load. The child never has to read an instruction.

## 3. Behaviours

| ID  | Behaviour                                                                                                                                                                                                                                                                                                                                                                    |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| B1  | **Decks by pattern.** One deck per phonics pattern, ordered so a deck only uses patterns already taught. Level 2 patterns (short vowels; `a_e ai ay`, `ee ea`; `i_e ie igh`, `o_e oa`; `ue ui`, `u_e ew`; `ou ow`, `oi oy`; `ar`, `or`; `ear eer`, `air are`; `au aw al`, `oo u`; `ur ir`, `or er`, schwa) plus a seeded Level 3 deck (`ck c k` = /k/). 8–12 words per deck. |
| B2  | **Hear & blend.** The word is spoken; the child taps grapheme tiles in order (`sh` · `i` · `p`). A wrong tap shows the correct next tile and lets them continue. There is no fail state, no score, no timer.                                                                                                                                                                 |
| B3  | **Hear & spell.** The word is spoken; the child types it on a large on-screen keyboard. The parent prompt is displayed for the adult: "say it, cover it, write it, check it".                                                                                                                                                                                                |
| B4  | **Bee round.** Ten words from the selected deck and its predecessors, in random order, no hints, one point per correct answer, score at the end. This is the only mode with a score.                                                                                                                                                                                         |
| B5  | **This week's words.** An adult can paste a list; it becomes the active deck immediately and is stored in `localStorage` only. Clearing it returns to the built-in decks.                                                                                                                                                                                                    |
| B6  | **Audio.** Every word in the built-in decks has a pre-generated audio file, one consistent voice, so the pronunciation never varies between sessions. If a word has no file (any pasted-in word), the app falls back to browser speech synthesis.                                                                                                                            |
| B7  | **Parent view.** For each word the parent sees one of three states — solid, shaky, not yet — derived from recent attempts, and can start a drill of the weakest five.                                                                                                                                                                                                        |
| B8  | **Fit and forget.** Landscape and portrait both usable, thumb-sized targets, no scrolling needed during a round. All progress stays on the device.                                                                                                                                                                                                                           |

## 5. Edge cases

- Pasted list is empty, has one word, has duplicates, has capitals or punctuation.
- Pasted list contains a multi-word phrase — treated as one item, spoken as-is.
- Word contains an apostrophe or hyphen: typed form must accept the same characters.
- No audio file and no speech synthesis in the browser: the word is shown as text
  with a visible "audio unavailable" mark, round continues.
- Rapid repeated taps or double submissions: one attempt recorded, not two.
- `localStorage` unavailable or full: the app still runs, paste-in lists are
  session-only, and the parent view says progress is not being saved.
- Rotation mid-round, and app backgrounded on iPad then resumed.

## 6. Pattern catalogue and "decodable"

The rule the deck validator enforces: a word is decodable in a deck if every one
of its graphemes maps to a pattern taught at or before that deck's unit. The
catalogue of patterns and their teaching order is data
(`specs/patterns.md`, mirrored into code as a typed table); a word that fails the
rule is a build failure, not a warning.

Words themselves are ours — invented, or drawn from ordinary English — never
transcribed from the printed material.

## 8. Decisions

| #   | Decision                                                                      | Alternative rejected, and why                                                                                                        |
| --- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| D1  | Vite + TypeScript, vanilla DOM; Vitest for logic, Playwright for UI and audio | Single-file HTML (no unit-test seam, no CI gate); React (a framework's weight buys nothing for five screens)                         |
| D2  | Pre-generated audio committed to the repo                                     | Browser TTS alone (voice varies by device and session — unacceptable for a bee); runtime TTS service (needs a backend and a network) |
| D3  | Static hosting on GitHub Pages                                                | Homelab behind the reverse proxy (needs a stable HTTPS URL the iPad can reach anywhere, and adds a moving part)                      |
| D4  | Progress in `localStorage`, never synced                                      | Accounts and cloud sync (out of scope for v1, and it would require collecting child data)                                            |
| D5  | Answer matching is case-insensitive and whitespace-trimmed                    | Exact match (punishes the keyboard, not the spelling)                                                                                |

## 9. Decisions taken 2026-10-20

1. **Voice** — one UK English female voice for all built-in words. Confirmed by
   Dave. Changing it later is a regeneration, not a code change.
2. **Hosting** — GitHub Pages now; **Cloudflare Pages later** (as with
   `maths.zt489.com`). The build is static assets in `dist/`, so the move is a
   deploy-config change, not an app change. Nothing in the app may depend on
   Pages-specific features — no Jekyll front matter, no `_headers`/`_redirects`
   until the move happens, relative asset paths only.
3. **Draw** — 8–12 words per deck, fixed order within a deck, shuffled per round.
4. **Bee round timing** — no per-word timer; the score is the only pressure.
5. **Level 3** — only `ck c k` is seeded in v1; the rest of Level 3 is a later
   spec.
